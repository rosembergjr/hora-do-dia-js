🕒 Projeto: Hora do Dia
📌 Descrição

O Hora do Dia é uma aplicação simples que identifica o horário atual do sistema e adapta a interface de acordo com o período do dia: manhã, tarde ou noite. Além de exibir a hora em destaque, o programa altera o fundo da página e a imagem, criando uma experiência visual dinâmica.

🚀 Funcionalidades
Exibe a hora atual automaticamente
Identifica o período do dia (manhã, tarde ou noite)
Altera o plano de fundo conforme o horário
Atualiza a imagem de acordo com o período
Interface simples e responsiva
🛠️ Tecnologias utilizadas
HTML5
CSS3
JavaScript
📷 Como funciona

O JavaScript captura a hora atual do sistema e, com base nela:

Define uma mensagem (Bom dia, Boa tarde ou Boa noite)
Troca a imagem exibida
Modifica a cor de fundo da página
